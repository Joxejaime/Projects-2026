# Postmortems

Postmortems here are written for **real** incidents, using [`template.md`](template.md). This lab has had none (it is a
practice environment), so there are deliberately no invented ones. Findings from the practice exercises live in
[`../game-days/`](../game-days/README.md).

Principles the template encodes:
- **Blameless**: describe systems and decisions, not people.
- **Numbers over adjectives**: impact and budget consumed come from metrics.
- **Detection is part of the incident**: how long between impact and the first page, and would a different alert window have been faster?
- **Action items have owners, types and dates**; "be more careful" is not an action item.
